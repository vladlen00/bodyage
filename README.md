# Возраст тела

Мини-аппа Студии Ирены Пол. Тест из семи физических блоков, на выходе
"возраст тела" = паспортный возраст плюс сдвиг по сумме баллов.

Живёт на GitHub Pages: https://vladlen00.github.io/bodyage/

## Стек

Чистый HTML, CSS и JS без фреймворков и без сборки. Файлы лежат в корне,
как в cycle и glutes.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Экраны как секции, переключаются `hidden` |
| `style.css` | Токены и компоненты, взятые из app.irenabio.com дословно |
| `config.js` | ВСЕ пороги, возрастные группы, таймкоды и тексты |
| `calc.js` | Чистая логика подсчёта: ни порогов, ни обращений к DOM |
| `app.js` | Экраны, плеер Kinescope, таймеры, Wake Lock |

## Правило порогов

Ни одного числа порога в логике. Всё живёт в `config.js`, потому что после
калибровки на живых людях цифры будут править. `calc.js` умеет только
арифметику над конфигом.

## Известное расхождение: подъёмы со стула

Протокол блока `chair_stand` просит КАСАНИЕ сиденья, а не полную посадку:
так снято в видео Ирены, и приложение обязано совпадать с видео.

Пороги же взяты из источника, где повтор засчитывался по ПОЛНОЙ посадке.
Касание быстрее, за 30 секунд повторов выходит больше, поэтому балл по
этому блоку сейчас ЗАВЫШЕН у всех, кто делает касанием, то есть у всей
аудитории теста.

Это осознанный компромисс, а не баг: совпадение с видео важнее. Снимается
калибровкой на живых людях, она и так в плане. Пометка продублирована в
`config.js` рядом с порогами блока.

## Видео

Одно видео на 13 минут 09 секунд на Kinescope, к нему семь таймкодов.
Плеер подключён через IFrame Player API и создаётся ОДИН раз, переходы между
блоками идут через `player.seekTo(seconds)`.

Параметр `?seek=` в URL намеренно не используется: он обрезает начало
манифеста и отнимает возможность отмотать назад.

Видео ограничено доменом в кабинете Kinescope. Привязка к
`vladlen00.github.io` покрывает этот репозиторий.

## Тема

Светлая по умолчанию, тёмная тумблером. Ключ `irena_theme`, тот же, что на
app.irenabio.com. Тема применяется скриптом в `<head>` ДО первого кадра,
иначе будет вспышка светлого.

ВАЖНО, проверено живым проходом 2026-08-04: в Телеграме мини-аппа открывается
с того же origin `vladlen00.github.io`, что и остальные мини-аппы студии, и
`localStorage` у них ОБЩИЙ. Один раз нажатый тумблер запоминается для всех
и переживает перезапуск Телеграма, поэтому "в Телеграме всегда светлая" - неверно.
Другой origin только у app.irenabio.com.

Тему самого Телеграма мы НЕ читаем: его SDK выставляет только свои `--tg-*`
переменные, наши стили их не используют.

## Кэш

При каждой правке CSS или JS поднимать `?v=N+1` у соответствующего файла
в `index.html`. Имена файлов не меняются.

## Что сделано и что впереди

Заход 1 (сделан): каркас без базы и без авторизации. Результат живёт только
в памяти страницы, F5 его теряет, так и задумано.

Заход 2: авторизация (`auth.js`, Дверь 2, `verify-app-token`), сохранение
замеров в Supabase.

Заход 3: плитка в studio, регистрация в BotFather.

## Терминология

Везде "возраст тела". Слов "биологический возраст" в интерфейсе нет нигде,
кроме дисклеймера под цифрой, где они нужны, чтобы сказать, чем результат
НЕ является.

## Текст интерфейса

Русский, на "ты", тёплый тон, нейтральный род. Женских окончаний и скобок с
окончаниями быть не должно: тест проходят и женщины, и мужчины.

Длинные и средние тире не используются нигде: ни в интерфейсе, ни в коде,
ни в комментариях, ни в коммитах. Только дефис.
